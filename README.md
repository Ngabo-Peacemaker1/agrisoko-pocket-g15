## 2. Product Purpose

**AgriSoko Pocket** is a mobile application that helps cooperative members, trainers, and stakeholders quickly identify **who built what** inside a project team. Instead of scrolling through documents, a user asks a natural-language question (e.g. *"Who built the mobile app?"* or *"Who is Ngabo Peacemaker?"*) and the app returns the matching team member with a short spoken-style introduction, their role, and the feature they shipped.

**Why it matters:** in multi-member student and startup teams, knowledge of who owns which feature is lost. AgriSoko Pocket makes that knowledge queryable in seconds, works offline, and degrades gracefully when the network is unavailable.
